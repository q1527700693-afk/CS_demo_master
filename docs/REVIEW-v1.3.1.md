# 网页版 1.3.1：道具伤害与关键表现

## 修复范围

- 云端解析保留了伤害事件，但旧导出丢失双方阵营，导致 HE/燃烧伤害被归为未知并错误显示成 0。新增统计服务使用本回合全员采样及击杀事件恢复阵营；不使用初始名单推测换边后阵营。区分对敌、自伤、队伤和无法归属；优先 dmg_health_real，旧文件只有 dmg_health 时明确显示原始伤害口径。
- 复盘重点改为首杀、首死、补枪、至少三杀回合、经济劣势获胜及装备优势被翻。普通 eco/force 失利、无条件“未被换人”和未知规则不会显示为通用“比赛事件”。支持只看“打得好的”。
- 补枪窗口为 5 秒，必须击杀刚刚击杀队友的同一名敌人。区分本人补枪、阵亡后被补枪；最后存活时阵亡不进入被补枪率分母。本人补枪转化分母为本人仍存活时的队友对敌阵亡数，不判断距离/可见性，不能等同于配合失误率。
- 经济数据按每回合实际阵营读取。只有双方人均装备存在明显差距才提取经济翻盘：低装备侧每人不超过 $2500，高装备侧至少 $3500，比例不超过 65%；手枪局排除。force 标签不会直接视为 eco。
- 每份个人报告展示 Rating（估算）。公开 Awpy 2.x HLTV-like 近似：Impact=2.13*KPR+0.42*APR-0.41；Rating=0.0073*KAST+0.3591*KPR-0.5329*DPR+0.2372*Impact+0.0032*ADR+0.1587。KAST 使用百分数。不是 HLTV 官方 Rating，也不是竞技匹配分；输入缺失/解析截断时留空。
- 主页取消跨玩家平均 Rating、平均 ADR、胜率，改为报告数量、覆盖地图、处理中和待处理记录。列表中的个人报告 Rating/ADR 仍各自归属分析玩家。
- 个人名片的高光公开展示三个接口仍未提供，功能保持原状，原有本人草稿/预览保留。未新增公开接口。

## 后端配套

新增 GET /api/v1/demo-analyses/{id}/performance（JWT + 所有权校验），从私有 parse.json 生成小型统计投影。旧报告即可使用，不覆写 Demo、解析文件、报告、AI 文本或用户数据。结果只缓存聚合投影，解析读取串行，缓存按报告 ID/玩家/文件修改时间区分。

新分析也应用相同规则；对应后端改动见 BACKEND-v1.3.1.patch。部署必须先更新后端再更新前端。源码基于 2026-11-04 的现网文件，保留所有 Dust2/AI/历史兼容改动，不应直接覆盖其他分支的不同实现。

开发机 backend_service 保留原版本和未提交修改。可用的隔离测试后端位于工作区 docs/frontend-v1.3.1/qa-source/backend。
