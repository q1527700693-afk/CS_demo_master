# 网页版 v1.3.2：训练空间遮挡修复

此前靶球在枪模之后清空深度缓冲并绘制，导致远处的球始终覆盖近处的枪和手臂，看起来像贴在枪身上。

现在先绘制房间和靶球，两者共享场景深度；再绘制第一人称枪模。转动视角时，枪和手臂会自然遮住落在其后方的部分靶球。将准星对准目标时，原有瞄准与命中计算继续使用相同的三维位置。

修改源文件为 training/CSPlatform/aim-trainer/src/renderer.js，并通过 scripts/sync-training.mjs 同步到 public/vector-trainer。版本号、工作台版本展示及构建 version.json 均为 1.3.2。目标生成、得分、灵敏度、枪模姿态和训练记录格式不变。

验证：训练引擎和枪口对齐单测；浏览器中比较房间、靶球、枪模的实际像素遮挡，覆盖不同视野、窗口比例和后坐力；验证准星瞄准后真实鼠标点击命中；前端单测、类型检查和生产构建；发布后核验线上版本及训练资源。

只发布前端。服务器已有的公开精选比赛接口及其他后端改动保留，不覆盖后端或数据库。GitHub 由所有者上传。

## 同版本缓存修复

首次 v1.3.2 发布漏掉了原生训练模块的独立缓存。页面会显示新版本，但固定 URL 的 training-loader.js、app.js 和动态 renderer.js 仍可能来自旧缓存，从而继续出现靶球覆盖枪身。

生产构建现在为训练入口和整个原生模块依赖图附加与 HTML 相同的构建 revision，包含动态导入、Three.js 共享依赖和样式表。前端加载器也使用这一 revision 请求训练入口。大体积模型与贴图保留原地址，避免无谓重复下载。原始 public/vector-trainer 快照保持未转换内容；scripts/training-release.mjs 只给生产构建的导入路径加版本，不修改训练规则。

新增回归：同一个浏览器先加载带一年缓存的旧版渲染器，再正常打开新版网页，检查全部训练模块都使用新 revision，并再次执行像素遮挡和真实点击测试；另外用大幅甩枪单靶在消音器轮廓处生成同视角的修复前后对照。产品版本保持 1.3.2。
