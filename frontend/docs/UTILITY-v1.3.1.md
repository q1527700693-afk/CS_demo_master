# 1.3.1 道具投掷次数补充修复

版本号仍为 1.3.1。

原“道具使用分布”读取 by_weapon.shots，但旧云端武器表只有伤害和击杀。原始解析文件还漏存了带玩家身份的投掷事件，所以出现只有高爆手雷、次数为横线的情况。

现在从 Demo 的 weapon_fire / shots 数据提取实际投掷，每个玩家、tick、道具类型只记一次。分别显示闪光、烟雾、高爆手雷、燃烧瓶、燃烧弹、诱饵弹。命中多人、多次火伤、伤害为零、无投掷者的轨迹均不会被当成投掷次数。

新解析保存 utility_throws 与完整性标记。旧报告从保留的原始 Demo 提取 utility-throws.json 私有补充文件，不覆盖 parse.json、report.json 或旧 AI；切换玩家时保留该文件，按分析玩家筛选。补充文件必须与原解析的 Demo SHA-256 相同，性能接口的缓存包含补充文件的修改时间。

完整记录中的零显示 0 次；缺失记录明确说明，不伪造零。解析截断时已知次数显示下限。兼容旧 ZIP 中明确提供的投掷计数；旧版闪光统计仍可作为闪光次数来源。

配套源码见 BACKEND-v1.3.1.patch。维护者先部署后端和 parser，再对保留 Demo 执行一次只读提取与私有补录，最后部署网页。此次修复不更新桌面客户端，也不提交或推送 GitHub。
