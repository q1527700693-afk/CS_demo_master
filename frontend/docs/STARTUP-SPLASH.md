# 视频开屏加载

## 当前规则

- 原视频按字节复制到 `public/media/startup.mp4`，时长约 5.056 秒，960 × 720，保留内容和音轨。
- 一进入页面就显示视频，Vue、路由和数据在后台同时加载。
- 应用先准备好：显示满 2 秒后淡入应用，不等待视频完整播放。
- 应用加载超过 2 秒：一就绪便进入，不等待当前视频结束；等待期间视频播完就从头循环。
- 每次打开/整页刷新都会播放；Vue 内部切换页面不重复开屏。
- 使用 `object-fit: contain` 完整显示 4:3 画面，其余区域黑色填充，适配桌面和手机。

视频始终静音播放，没有声音开关。它只作为加载背景，暂停、缓冲、无法播放或自动播放被阻止都不会延长进入时间。提示文字统一为“正在加载…”。
底部进度条结合已完成的应用启动阶段与最短 2 秒显示时间，采用二者中较慢的进度；它不是网络下载字节百分比。应用就绪且显示满 2 秒后才显示 100% 并淡入工作台，视频播放进度不再参与判断。
应用背景在开屏期间隐藏并设置 `inert`，避免点击或键盘误触。离开开屏后销毁视频节点、停止播放并解除媒体资源引用。

## 应用就绪的定义与新增模块

`src/app/bootstrap.ts` 等待模拟服务（启用时）、登录恢复、首屏路由组件、首屏初始化任务、字体和一次布局完成。
首屏资料、复盘列表/报告、车队、总览的数据加载，以及训练的模块挂载、样式和初始 3D 加载，均计入初始化。请求失败且页面已经能显示错误/重试时，也属于可以进入的终态。

新页面有异步初始化时，使用 `src/app/startup-tasks.ts` 的 `trackStartup` 登记：

```ts
onMounted(() => trackStartup(loadInitialData()))
```

Vue 挂载时同步调用 `trackStartup`；传入的 Promise 应覆盖首次加载需要的工作。后续导航和用户主动操作不重新触发开屏，不要将持续轮询、游戏运行循环或用户操作登记为启动任务。
训练等待逻辑只在平台的 `loader.ts` 适配层读取原模块的加载状态，未修改游戏文件。若队友改变挂载协议或加载状态字段，同时更新适配层。

## 异常处理

- 应用启动失败：保留开屏并显示“重新加载应用”，不会进入空白页。
- 视频资源损坏或不可播放：隐藏视频，继续显示黑色背景、加载提示和进度条；仍按应用就绪与 2 秒最短显示规则进入，无需手动确认。
- 暂停或自动播放受限：不阻止应用进入，也不要求用户点击播放。

## 换视频

替换 `public/media/startup.mp4` 后重新构建发布即可，视频长短不影响最短进入时间。如需调整最短显示时间，修改 `src/app/startup-gate.ts` 中的 `MIN_STARTUP_MS`，当前为 `2000` 毫秒。

开屏本身不改变 Vite 开发服务的启动方式，也不负责启动尚未运行的后端或本地桌面进程。将来制作桌面安装包时，可以继续使用这套前端开屏流程。
