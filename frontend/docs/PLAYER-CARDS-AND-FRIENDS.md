## 训练成绩接入

原游戏的 47 个运行文件均保留原样。仅宿主 `TrainingPage.vue` 通过现有 `mountTrainer(..., { onComplete })` 回调接收已完成的 session。

账号名片的最佳记录保存在新键 `csdm.training.bests.v1.<账号标识>`，标识包含 user id、username、createdAt。训练开始挂载时捕获账号与 token；完成前账号或 token 改变则不归属成绩；访客成绩不归给任何账号。新名片系统不会读取或自动认领共享的 `vector.trainer.sessions.v1` 历史。

成绩只存在本机当前浏览器，不会被其他玩家读取或在另一台设备出现。目前不上传云端，也没有公开战绩、排行榜或防作弊认证。

- 网格点射、大幅甩枪、精准微调：最高得分。
- 反应测试：最低平均反应用时，单位 ms；不是单次最快点击。
- 平滑跟枪：最高在靶率，单位 %。
- 按原游戏 `comparisonKey` 对规则版本、模式、时长、难度、输入方式和适用的灵敏度/FOV 分组；反应测试只按规则/时长区分。
- 不同参数组不混比，多组时可在名片卡片切换，默认最近训练的组。
- 中途调整参数、未完成、旧版或无有效指标的回合不计最佳。完成 session.id 去重，保存摘要，不保存鼠标输入事件。
- 每组保存最佳和有效轮次，之后练出较低成绩不会覆盖最佳。

原游戏自己的记录页、导出和清空仍只管理其原有共享历史。清空游戏历史不会删除名片最佳记录，两套存储不能互相冒充账号或云端数据。

## 验证

`npm run test:cards` 保留名片、训练五模式、本机成绩隔离与数字 ID 查询的只读回归；好友完整交互由 `npm run test:social` 使用真实隔离后端验证。两个脚本均需要外部 Playwright 和 Chrome，详见 [联调说明](SOCIAL-LOBBY-INTEGRATION.md)。
