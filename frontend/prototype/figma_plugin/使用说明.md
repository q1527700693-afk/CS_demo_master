# 一次补齐 Figma 原型

目标文件：[CS Demo Master · 软件工程交互原型](https://www.figma.com/design/iseRACZAMwJMohHfqKDkEP)

这个本地插件只操作上述设计文件当前页面中的 CS Demo Master 画布。它会补齐 3 个缺失画布、将 34 页的 442 个可见链接设为 Figma 原型点击跳转，并将“总览”设为演示起点。再次运行会替换自己创建的透明点击热区，不会重复叠加。

## 运行

1. 在 **Figma 桌面版**打开目标设计文件。
2. 在画布空白处右键，选择 **Plugins / 插件 → Development / 开发 → Import plugin from manifest / 从清单导入插件**。
3. 选择本文件夹中的 `manifest.json`。如果 Figma 提示插件 ID 需生成或替换，按提示生成并保存清单。
4. 再次右键画布，选择 **Plugins → Development → CS Demo Master 原型连线**，等待完成提示：`34 个画布，442 条点击连线；新建 3 个画布`。
5. 点击 Figma 右上角 **Present / 演示**，从“总览”开始，检查“比赛概览 → 回合复盘 → 道具与生存 → 详细数据”和“发布车队 → 发布成功 → 队长管理 → 已发车”。
6. 在 Figma 分享设置中将访问权限调整为“知道链接的任何人可查看”，复制原型演示链接。

插件没有网络请求，也不读取账户信息。导入与运行操作按照 [Figma 官方本地插件说明](https://help.figma.com/hc/en-us/articles/38457121114263-Create-a-Figma-Design-plugin-with-the-Figma-MCP-server-and-agentic-tools)。
