# 单文件交互原型导入墨刀

使用 [cs-demo-master-modao-single.html](cs-demo-master-modao-single.html)。这是一个不依赖外部资源的 HTML 文件，包含 20 个可切换界面；页面导航通过文件内部 `#页面名` 切换，不涉及 `*.html` 相对链接。

已在本地 Chrome 中检查：报告的比赛概览 → 回合复盘 → 道具与生存 → 详细数据，以及校园车队 → 发布车队 → 车队详情 → 领取组队码；共检查 101 个内部链接均指向现有界面。

## 在墨刀中操作

1. 在墨刀工作区打开一个原型项目，找到“HTML转墨刀”。
2. 上传 `cs-demo-master-modao-single.html`，选择或保留默认的 **AI 组件 / HTML 容器**。
3. 不要转换为原生可编辑元素；转换后 JavaScript 导航可能丢失，需要重新连画布。
4. 在墨刀的预览或演示模式点击报告四标签、车队发布流程及侧栏导航，确认能在同一个组件内切换页面。
5. 点击右上角“分享”，选择可响应交互的演示模式；用未登录窗口检查分享链接。

旧版 20 画布项目可以保留作为原生可编辑设计稿。答辩的可点击演示建议使用这个单文件 AI 组件。两种形式若同时提交，请在博客中标明哪个链接是交互演示。

如导入后只出现第一页或点击无效，说明当前入口把 HTML 转成了原生元素，而非保留 AI 组件。回到 HTML 转墨刀入口确认导入形态；不要继续逐个修复旧版的 92 个外部链接。
