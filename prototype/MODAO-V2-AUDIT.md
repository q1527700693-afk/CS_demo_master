# 墨刀原型二次自查

旧项目：[未命名原型](https://modao.cc/proto/design/pb2mcpVZ2KZ1VzqC0BA2)，保留用户在编辑器中的修改。当前未覆盖旧项目。

## 查出的结构问题

1. 旧版只有 10 张主画布。报告顶部四个标签被导成 `#overview`、`#rounds`、`#utility`、`#data` 外部锚点，没有四张可跳转的报告状态画布。
2. 旧版 HTML 的脚本弹层被墨刀解析成 17 张额外画布，集中放在主画布区域之外，因此会出现跳转后层级和位置不对。
3. 前端已有的分析进度、本地复盘库、本地解析、训练设置与记录、车队发布与领码、好友申请、资料编辑等状态没有充分覆盖。

## 新版源文件

- `modao_pages/`：34 个脚本零依赖的显式状态页面，保留完整清单。
- `modao_core/`：由于墨刀 MCP 一次最多导入 20 页，合并辅助状态后形成的 20 张核心画布。报告四个标签各有独立页面，车队发布、详情和领码各有独立页面；不会再生成脚本弹层画布。
- `cs-demo-master-modao-v2-core.zip`：20 页导入包。

20 页核心稿的侧栏用静态栏目名表达当前模块，主流程通过内容区的按钮连接。这样减少重复的无效外部链接。实际导入后仍需在墨刀编辑器中把 HTML 相对链接重定向到对应画布；当前 MCP 没有批量修改画布交互的功能。

34 页版本的首次导入被墨刀拒绝，返回“可导入页面数量不能超过 20 个”。用户再次授权后，20 页版本已导入为[墨刀 v2 编辑项目](https://modao.cc/proto/design/pb2mcpVZ2dmFPinkMQZT)。读取项目结构确认恰好 20 张主画布、没有额外弹层画布。导入器仍将 92 条页面链接识别为相对 HTML 外部链接；去重后的目标画布清单见 [MODAO-V2-INTERACTIONS.md](MODAO-V2-INTERACTIONS.md)。当前项目尚未完成原生交互连接或公开演示分享。
